# ChemCore V6 — تحديثات سجلات المواد بالاستعلام الانتقائي

**قناة المستخدم:** `updates/chemcore-records/v6/index.json` على `HazRob/HazRob-Tank`.  
**مصدر التأهيل:** المكتبة العلمية المركزية. لا يعيد Android تقييم الأدلة أو إعادة تأهيل M4 بعد المزامنة.

## النشر من المكتبة المركزية

تنشر المكتبة المركزية فهرسًا صغيرًا من هذا الشكل، بعد الانتهاء من مراجعتها العلمية الخاصة:

```json
{
  "schema": "hazrob-tank-reference-delta-v6/1",
  "revision": "central-publication-revision",
  "records": [
    {"uid": 77, "cas": "74-82-8", "sha256": "<sha256 of exact UTF-8 record bytes>", "file": "77.json"}
  ]
}
```

المثال أعلاه **توثيقي ولا يثبت توفر أي بصمة أو منحنى للميثان**. لا تنشر السجل قبل اعتماد المحتوى المركزي. الملف الحقيقي `records/77.json` يحتوي القيم المنشورة فعلًا فقط:

```json
{
  "uid": 77,
  "cas": "74-82-8",
  "facts": [
    {
      "key": "mq_curve_reference",
      "source_id": "HAZROB_RESEARCH",
      "source_url": "https://github.com/HazRob/",
      "text": "source reference and method",
      "library_status": "QUALIFIED"
    }
  ]
}
```

`library_status` يكون `AVAILABLE` أو `QUALIFIED` بحسب **قرار المكتبة قبل النشر**. الأنواع المعروضة للتطبيق: `fingerprint_reference`، `mq_curve_reference`، `ppm_reference`، `m4_reference`، إلى جانب خصائص وصفية `formula`، `molar_mass`، `reference_note`. الحقائق الوصفية لا تُحوّل بذاتها إلى معايرة جهاز أو إنذار غاز.

## سلوك التطبيق

1. يتحقق من مراجعة الفهرس ويستعلم عن مواد UID الحالية فقط، مع عدم تغيير UID أو الجلسات أو المعايرات أو ملفات Stable المدمجة.
2. إذا كان SHA-256 للسجل مطابقًا للمراجعة السابقة فلا يعيد جلبه. بخلاف ذلك يجلب JSON صغيرًا للـUID، ويتحقق **تقنيًا** من سلامة النقل وأنه يخص UID/CAS المقصودين، لا علميًا من تأهيل المصدر.
3. يُحدّث سجل المادة داخل SQLite كمعاملة واحدة. يتلقى التطبيق حالة `QUALIFIED` من المكتبة كما هي، وتظهر بوضوح تحت «✓ مكتبة»، مقابل «✓ جهاز» للتأهيل الميداني المحلي.
4. كل سجل منشور هو **الصورة الحالية الكاملة لإمكانات UID**؛ حذف إمكان من ملف المادة يؤدي إلى سحب علامته في القوائم بعد الاستعلام التالي. لا تُحذف التجارب التاريخية.
5. تحديث مجموعة المواد يجري على دفعات حتى 25 مادة، والاستعلام عن مادة واحدة يتم بزر خاص في شاشة تجارب المطور. بعد المزامنة يستدعي التطبيق `host.refreshAllTabs()` لتحديث القوائم والحالات.

## حالة هذا الفرع

الفهرس الحالي **فارغ عمدًا** ولا يحتوي على قدرات مخترعة. لم تُنشر بعد سجلات إضافية مؤهلة على قناة `main`. اختبار Android N09 يولّد بيانات اصطناعية محصورة داخل المحاكي للتأكد من ظهور وسحب الإمكانات؛ لا يُرحّل أي منها إلى المكتبة الحقيقية.

**معايير السلامة:** التأهيل المركزي منفصل عن التحقق من عدم فساد البيانات في النقل، ولا يمكن لأي استعلام كتابة `R0` أو `Rs` أو شروط اعتماد الإنذارات.
