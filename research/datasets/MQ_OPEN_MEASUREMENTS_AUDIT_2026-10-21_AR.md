# HazRob Tank | تدقيق أولي لمصادر قياسات MQ التجريبية المفتوحة
**التاريخ:** 2026-10-21 | **الفرع:** `research/mq-open-measurements-audit-20261021` | **لا دمج تلقائي في ChemCore**  
**القاعدة:** `main` عند `632745078a48b12d9de68b0ce66ba214cc87c4d4`.
**حساسات Tank المستهدفة:** MQ2، MQ3، MQ4، MQ5، MQ7، MQ8، MQ9، MQ135.

## 1. الخلاصة العلمية
- وُجد أرشيف **Zenodo 17285312** يصرّح باستخدام **الأنواع الثمانية كاملة** مع MQ6 في بيئة قياس لرائحة الأغذية؛ وجود الأنواع موثق في صفحة النشر، **ولم يُفحص محتوى ZIP داخلياً بعد**. لذلك لا تُثبت الصفحة وحدة الإشارة أو وجود R0 أو تركيز مرجعي مستقل.
- وُجدت قياسات **مقاومة Rs بالأوم** وحرارة/رطوبة وسلاسل زمنية للأجزاء المأخوذة من مصدر **Mendeley mwmhh766fc الإصدار 3**، تحتوي 7/8 حساسات Tank باستثناء MQ7؛ هدف الدراسة فساد اللحم ومؤشر بكتيري، **لا هوية الغاز النقي أو ppm**.
- فُتح فعلاً ملف GitHub العام `TakMashhido/Gas-Sensors-Measurements-Dataset/Gas_Sensors_Measurements.csv` وتم فحص جميع **6400 صف** و**7 أعمدة MQ** (MQ2، MQ3، MQ5، MQ6، MQ7، MQ8، MQ135) والقيم الرقمية وفئات NoGas/Perfume/Smoke/Mixture (1600 لكل فئة). المتوسطات وقيم الحدين لكل الحساسات مطابقة تماماً لجدول MultimodalGasData الأكاديمي لعام 2022. **تعامل المصدران كعائلة بيانات واحدة حتى إثبات اختلاف سجل القياس؛ لا تجمع 6400+6400**.
- توجد مجموعة تربط **MQ7/MQ9/MQ135** بإشارة **CO2 مرجعية** بمسابقة Zindi (اسم المصدر Chemotronix) لكن تتطلب قبول شروط تنزيل المسابقة؛ **لم يُستلم الملف أو يدقق بعد**. لا تُنقل وحدة CO2 إلى CO/CH4 ولا تُعامل كمعايرة لجميع الغازات.
- نُشرت 2484 قراءة و8 حساسات لـ CO في دراسة 2026؛ **البيانات ليست تنزيلًا عاماً**، بل "accessible from corresponding author upon reasonable request" حسب بيان توفر البيانات؛ تدرج مرجعاً علمياً ولا تُسجل كمصدر ملفات جاهز.

## 3. دليل مباشر للملف MQ-EXT-03
مسار GitHub: `TakMashhido/Gas-Sensors-Measurements-Dataset` `Gas_Sensors_Measurements.csv`. Blob Git SHA: `451fdd05a18db8531abc219089de071ccc0dd461` (ليس SHA256 لمحتوى البايت). 
- `6400` صف بيانات، الأعمدة: `Serial Number,MQ2,MQ3,MQ5,MQ6,MQ7,MQ8,MQ135,Gas`.
- توزيع الفئات: `NoGas=1600, Perfume=1600, Smoke=1600, Mixture=1600`.
- المتوسط/الحد الأدنى/الحد الأعلى: MQ2 = 677.59 / 502 / 824؛ MQ3 = 462.02 / 337 / 543؛ MQ5 = 404.58 / 291 / 596؛ MQ6 = 399.76 / 311 / 524؛ MQ7 = 565.95 / 361 / 796؛ MQ8 = 542.47 / 220 / 794؛ MQ135 = 416.73 / 275 / 589.
- أول صف بيانات `0,555,515,377,338,666,451,416,NoGas`.
- تطابقت كل هذه الإحصاءات مع جدول الدراسة: https://www.mdpi.com/2306-5729/7/8/112 ؛ **فرضية المصدر المشترك قوية لكنها لا تستبدل حساب SHA256 لنسختين**.
- `Serial Number` يُعاد استخدامه عبر الفئات (أول/آخر المجموعة يبدأ 0 ثم يصل 1599)، فلا يُعامل معرّف تعرّض عالمي أو تقسيم جلسة أو زمن حقيقي. **6400 صف ليست 6400 تعرّضاً مستقلاً**.

## 4. مصفوفة الأهلية للتقنيات الثمانين
- 01.1 ADC→Rs: MQ-EXT-02 يقدم Rs؛ MQ-EXT-03 ADC فقط، ولا يجوز تحويله دون RL/جهد/نوع ADC/الدائرة.
- 01.2 R0 ومعايرة التركيز: **غير مؤهل تلقائياً لأي مصدر**؛ لا تستخرج R0 من صِفات الطعام/العطر.
- 01.5 تعويض بيئي: MQ-EXT-02 و05 و07 تحتوي مؤشرات بيئية بخصائص مختلفة؛ لا يجوز نقل معامل التعويض بين العتاد دون تحقق.
- 02.1–02.7 معالجة/ميزات/بصمات/اختيار: MQ-EXT-01/02/03/04 بحسب توافر ملف الزمن الأصلي.
- 03.1–03.8 PCA وLDA وقابلية التمييز واختبارات إسقاط الحساسات: MQ-EXT-02/03/04 بشرط حجب مقاطع العينات والتسجيلات والدفعات المستقلة.
- 04.1–04.10 التعرف: MQ-EXT-03 يصنف **الظروف NoGas/Perfume/Smoke/Mixture** ولا يُحوّل هذه الأسماء إلى جزيئات نقية؛ MQ-EXT-04 يصنف **أصناف الخل** فقط.
- 05.1–05.9 التقدير الكمي: فقط معيار كيميائي مستقل مثبت وحدات وتحضيرات؛ **غير موجود مثبتاً في البيانات المفتوحة التي فحص محتواها**؛ QQ/TVC جودة غذاء ≠ تركيز غاز ppm. MQ-EXT-07 مرجع CO2 محتمل لكن يحتاج تدقيق المصدر الفيزيائي.
- 06.1–06.9 الثقة: تجرى على تصنيفات صحيحة المصدر، مع اختبار grouped، لا احتمال سلامة الغاز.
- 07.1–07.10 الانجراف/الجلسات/الأجهزة: MQ-EXT-02 خمس سلاسل مستقلة؛ MQ-EXT-07 ثلاثة أجهزة حسب الوصف؛ تقسيم كل سلسلة أو جهاز كاملاً.
- 08.1–08.12 CNN/TCN/LSTM/GRU/GNN والخلائط: استخدم السلاسل الحقيقية عند توافرها؛ فئة Smoke+Perfume خليط تشغيلي ولا تزود نسب المكونات المستقلة اللازمة لـ Unmixing.
- 09.1–09.6 الشم المكاني: لا يدعي أي مصدر أعلاه قياسات موقع/مسار/رياح تصلح للتحقق المكاني.
- 10.1 أدلة الغياب: تحتاج تقدير الحساسية/عدم الكشف بالتركيز المرجعي؛ `NoGas` وحده لا يثبت قدرة استبعاد غاز.

## 5. قرار مصدر البيانات والإجراء التالي
1. ابدأ بجلب ZIP `MQ-EXT-01` ثم تدقيق بنية الملفات وطول السلاسل ووحدات القراءة وتكرار التجارب، وحساب SHA256 الفعلي؛ تقرير "8/8" الآن يعني **مطابقة الأنواع في بيان النشر** وليس تحققاً من البيانات الداخلية.
2. جلب Mendeley إصدار 3 للمجموعة `MQ-EXT-02` مع الحفاظ على التعريف الخماسي لسلاسل عينات اللحم ووحدة Rs بالأوم.
3. قبول `MQ-EXT-03` كأصل واحد؛ لا تضاعفها عن طريق إصدارات GitHub/Zenodo ومصدر الدراسة. ابحث عن حقول session/time الحقيقية؛ إن غابت فتوثيقها `GROUPS_UNAVAILABLE` وليس تصنيعها.
4. احصل على مراجع CO2 من Zindi إذا سمحت الشروط، ثم دقق مصدر المعايرة والربط بالـ ppm.
5. عند قبول أي مصدر، احفظ أصل الملف بلا تعديل، وSHA256، والترخيص وDOI والرابط وتاريخ الجلب وبنية الأعمدة، ثم نواتج اشتقاق منفصلة وملف `grouped splits`. تحظر إضافة أي من هذه التجارب إلى `Tank G3`.

**قيد حاسم:** هذا تقرير **اكتشاف وتدقيق**، وليس استيراداً مكتملًا للملفات الخام المفتوحة أو تدريباً جديداً. كل نتائج G3 على جهاز Tank نفسه تبقى **0/80** حتى التجارب المرجعية المستقلة.
