# 05.2 Multipoint Calibration — HazRob Tank

**PROTOTYPE** of piecewise log-log interpolation through >=3 independently measured reference points for **one identified gas and one MQ sensor**. Input pairs are (known concentration ppm, observed Rs in ohms); R0 in ohms. Fit checks strictly increasing concentrations and strictly monotonic Rs/R0 response, then supports forward interpolation (expected Rs) and inverse interpolation (estimated ppm). Refuses extrapolation outside measured range. Unlike 05.1's single power-law fit, local segments may capture curvature without a global power law.

Important limitations: this model interpolates **exactly through noisy reference measurements** and can overfit; does not quantify measurement uncertainty, replicate variation, hysteresis, drift, temperature/humidity, cross-sensitivity, mixtures or saturation. Monotonicity may fail on real MQ data; rejection means inspect measurements, not silently force monotonicity. No calibration of gas identity, no operational safety use. R0 is sensor- and protocol-specific; manufacturer typical curves are not instrument-traceable calibration. Independently validate on held-out concentration levels, sessions and devices. Test concentrations must not be reused for fit/selection. 16 synthetic tests authored, clean-checkout execution and real Tank validation pending. Run `cd research/techniques/05.2 && python -m unittest -v`. No production changes.
