## الخلل المحدد

## الإصلاح المنفذ
1. فحص **كل صف** في ملفات CSV، ورفض عدم تطابق عدد الأعمدة، ورأس الأعمدة الفارغ أو المكرر، وملفات CSV دون صفوف بيانات؛ واستخدام `csv.reader(strict=True)`.
2. تفعيل `object_pairs_hook` لرفض مفاتيح JSON المكررة في جميع المستويات، و`parse_constant` لرفض `NaN/Infinity/-Infinity`.
3. إضافة أربعة اختبارات سلبية مستقلة: صف CSV لاحق غير متسق مع تجزئة صحيحة؛ رأس CSV مكرر؛ مفتاح JSON مكرر؛ وقيمة JSON غير منتهية. تستخدم كلها حزم **اصطناعية** ولا تثبت غازاً أو تركيزاً.
4. بقيت قاعدة التأهيل كما هي: `G2_PASS_CANDIDATE_REQUIRES_REVIEW` لا تعني اعتماداً؛ بيانات `G2_INDEPENDENT_EVIDENCE.json` الحالية `records: []`.
