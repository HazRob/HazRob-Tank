# G2 — تدقيق سلامة تحليل JSON لحدود MQ4 الزوجية (1 نوفمبر 2026)

**النطاق:** ملف التحليل البحثي `g2_mq4_pairwise_frechet_bounds.py` فقط؛ لا تعديل للمحرك Stable أو تطبيق Android أو الفريموير.

## الخلل المعالج
كان التحليل يقرأ سجل الأدلة المستقلة باستخدام `json.loads` الافتراضي، الذي يقبل مفاتيح JSON المكررة ويحتفظ عادة بالقيمة الأخيرة. لذلك كان ممكناً تمرير سجل يحتوي على `"records":[{"unverified":true}]` ثم `"records":[]` داخل الكائن نفسه، فتختفي القيمة الأولى عند الفحص. لم يكن ذلك دليلاً على ترقية علمية حدثت فعلاً؛ لكنه مسار تساهل غير مقبول في أداة بحثية تدّعي منع الاستدلال بلا دليل مستقل.

## الإصلاح والتحقق
أضيف محلّل صارم يرفض المفاتيح المكررة في جميع مستويات JSON، ويرفض `NaN` و`Infinity` وأعداد الفاصلة العائمة التي تتجاوز المجال المحدود مثل `1e10000`. كما يرفض الكائن الجذري غير الصحيح، ويحافظ على قبول إعادة ترتيب المفاتيح السليمة. أضيفت ثمانية اختبارات انحدار حتمية تشمل أمثلة الخداع ومثال سجل أدلة غير فارغ.

لا تتغير نتائج Fréchet المثبتة في JSON لأن البيانات المرجعية لم تتغير. بصمة ملخص المصدر تبقى `0df1ed3776aa515973886bad18153498325a038040bdb08d8a0a70ab35f5a1ea`، وتبقى مصفوفات الالتباس الأصلية ملخصاً استعاديّاً لا يثبت استقلال التعرضات ولا الأداء التنبؤي ولا سلامة الإنذار.

## شرط الاستئناف
شغّل بوابة GitHub Actions G2 على الالتزام الجديد، وتحقق من نجاح جميع الاختبارات الثمانية الجديدة ومن بقاء `g2_pass_candidates=0` و`g2_blocked=80` و`source_blocked=14` وسجل الأدلة `records=[]`. لا ترفع أي تقنية إلى G2/G3 دون تعرضات مستقلة ومعايرات مرجعية قابلة للتتبع وحجب مسبق لمجموعات الاختبار.
