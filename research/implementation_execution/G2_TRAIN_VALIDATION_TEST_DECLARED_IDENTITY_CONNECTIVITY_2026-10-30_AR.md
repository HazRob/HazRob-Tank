# G2 — اتصال هوية المنشأ المعلنة بين التدريب والتحقق والمعايرة والاختبار

التاريخ: 2026-10-30. النطاق: `HazRob Tank`، فرع البحث فقط. لا يشمل هذا التغيير ChemCore Stable أو Android أو الفريموير.

## المشكلة

قد توجد علاقة غير مباشرة بين بيانات `test` وبيانات `train` أو `validation` أو `calibration`، حتى لو اختلفت معرفات المجموعات، نتيجة اشتراك جلسات أو دفعات تعرض أو تعرضات أو عينات فيزيائية **معلنة**. تدقيق المعايرة والاختبار وحده لا يصف اتصالات التدريب/التحقق مع الاختبار بصورة منفصلة.

## التنفيذ

أضيفت في `g2_declared_holdout_partition_audit.py` ثلاثة مؤشرات تشخيصية: `train_test_declared_identity_component_overlap` و`validation_test_declared_identity_component_overlap` و`test_non_test_declared_identity_component_overlap`. بقي `calibration_test_declared_identity_component_overlap` دون تغيير في معناه. تحسب المؤشرات عبر مكونات اتصال `group_id` المرتبطة بمعرفات `session_id` و`exposure_batch_id` و`exposure_id` و`physical_sample_id`، مع استبعاد `device_id` من روابط الاتصال.

كل مؤشر ثلاثي الحالات: `true` يعني وجود اتصال **معلن** مباشر أو انتقالي؛ `false` يعني عدم كشف اتصال عند اكتمال جميع أعمدة الهوية ووجود القسم المعني؛ `null` يعني أن نقص هوية معلنة أو غياب القسم لا يسمح بحكم سلبي. تبقى الأعلام `source_provenance_authenticated=false` و`independent_physical_exposures_verified=false` و`g2_qualified=false` و`g3_qualified=false` ثابتة.

لا تمثل هذه المؤشرات إثباتاً للتسرب الفيزيائي أو استقلال التجارب؛ ويجب تفسير `false` على أنه **عدم كشف في بيانات منشأ غير موثقة** وليس شهادة استقلال.

## الاختبارات

أضيفت عشر حالات اصطناعية في `test_g2_test_partition_identity_connectivity.py`: فصل معلن، تداخل تدريب/اختبار، تداخل تحقق/اختبار، اتصال انتقالي عبر التحقق، نقص معرّف العينة مع اتصال غير مكشوف، نقص المعرّف مع اتصال مثبت، غياب التحقق، إعادة استخدام الجهاز فقط، نقص الجلسة، وثبات المخرجات عند إعادة ترتيب الصفوف.

إعادة الإنتاج: `python -m unittest discover -s research/implementation_execution -p 'test_g2_*.py' -v`. تنفذ GitHub Actions بوابة `g2-signal-lineage-v4.yml` الاختبارات وتدقيق 80 تقنية وحارس النشر. لا يُعلن نجاح CI حتى التحقق من تشغيل الالتزام الذي يضم الاختبارات.
