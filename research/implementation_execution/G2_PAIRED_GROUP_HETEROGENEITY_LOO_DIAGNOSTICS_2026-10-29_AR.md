# G2 — تشخيص عدم تجانس المجموعات وحساسية حذف مجموعة واحدة للفارق المقترن
**التاريخ:** 2026-10-29  
**النطاق:** HazRob Tank — فرع البحث فقط، دون أي تعديل على ChemCore Stable أو Android أو الفريموير.  
**الحالة:** أدوات إحصائية وصفية/اختبارات اصطناعية، وليست إثباتاً تجريبياً أو اعتماد G2/G3.

## الدافع
قد يبدو فارق دقة النموذج وخط الأساس موجباً عند جمع كل التعرضات، بينما يعتمد معظم الأثر على مجموعة اختبار فيزيائية كبيرة واحدة أو تختلف إشارة الأثر بين الجلسات. فاصل bootstrap المقترن وحده لا يكشف بوضوح تركّز وزن التعرضات ولا حساسية التقدير لحذف مجموعة واحدة. يجب كشف ذلك قبل تفسير النتائج، دون الادعاء بأن معرّفات المجموعات تثبت استقلالها الفيزيائي.

## الإضافة الحسابية
وُسّعت `g2_paired_delta_diagnostic.py` لتصدر، بجانب الفارق المقترن وفاصل إعادة السحب الحالي:
- `model_accuracy` و`baseline_accuracy` محسوبتين من نفس مجموعات الاختبار.
- عدد المجموعات ذات الفارق الموجب والسالب والمتعادل (`group_positive_delta_count`, `group_negative_delta_count`, `group_tied_delta_count`).
- الحد الأدنى والأعلى لفارق الدقة داخل كل مجموعة (`group_delta_min`, `group_delta_max`).
- أصغر وأكبر فارق مجمع بعد حذف مجموعة فيزيائية واحدة في كل مرة (`leave_one_group_out_delta_min`, `leave_one_group_out_delta_max`).
- أكبر حصة تعرضات لمجموعة واحدة (`largest_group_exposure_fraction`).
- مؤشر كيش الوصفي لتركيز أوزان المجموعات: `(sum n_g)^2 / sum(n_g^2)`، واسمه `kish_effective_group_count_descriptive_only`. **ليس** تقديراً مثبتاً لعدد مجموعات مستقلة فعلياً ولا اختباراً للقدرة الإحصائية.

كل الحسابات حتمية ولا تستخدم تسميات غازات جديدة أو تغير مخرجات ChemCore Stable. تبقى إعادة السحب مقترنة وبوحدة المجموعة الفيزيائية، وتظل نسبة الفروق غير الموجبة من bootstrap **ليست قيمة p**.

## اختبارات الانحدار
أضيفت ثلاثة اختبارات اصطناعية إلى `test_g2_paired_delta_diagnostic.py`: (1) حالة ثلاث مجموعات بأوزان غير متساوية وإشارات فارق موجبة/سالبة/صفرية، (2) مجموعة تهيمن على 99% من التعرضات لإظهار ضعف الاستقرار عند حذف مجموعة، (3) تطابق جميع المخرجات عند تغيير ترتيب معرّفات المجموعات. لا تشكل هذه الحالات قياسات غاز مستقلة.

## إعادة الإنتاج
```bash
python -m unittest discover -s research/implementation_execution -p 'test_g2_*.py' -v
python research/implementation_execution/g2_paired_delta_diagnostic.py \
  --per-group-csv research/g2/evidence/<technique>/<dataset>/<run>/metrics_per_group.csv \
  --seed 20261029 --resamples 2000 --output paired_delta_research_only.json
```
يتطلب الأمر الثاني ملفاً أصلياً مؤهلاً غير موجود حالياً في سجل الأدلة المستقلة. SHA256 لملف CSV يربط النتيجة بالبايتات، ولا يثبت أصالة القياس أو صحة المراجع الفيزيائية أو الاستقلال أو التعمية.
