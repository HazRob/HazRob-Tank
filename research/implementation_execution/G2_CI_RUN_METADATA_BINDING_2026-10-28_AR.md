## الإصلاح البحثي
أصبحت بوابة الاتساق تقرأ `ci_run.json` وتطلب كائناً صالحاً مع ربط `run_id` و`head_sha` بسجل التقنية، والتحقق من الصيغ الدقيقة لمعرّف التشغيل وSHA، وهوية المستودع `HazRob/HazRob-Tank`، ومسار بوابة G2 `.github/workflows/g2-signal-lineage-v4.yml`، وعنوان التشغيل الرسمي، ونوع الحدث، و`conclusion=success`. تُرفض الأرقام المنطقية أو العشرية في معرّف التشغيل حتى لو ساوت عدداً صحيحاً في بايثون. عند التعارض تُضاف `CI_RUN_METADATA_NOT_BOUND_TO_G2_WORKFLOW` وتُحجب أهلية المرشح.

أُضيف `test_g2_ci_run_binding.py` بخمسة اختبارات تشمل مرجعاً اصطناعياً إيجابياً وضوابط سلبية لإعادة حساب SHA256 بعد تبديل معرّف التشغيل أو الرابط أو الالتزام أو اسم سير العمل أو حالة التشغيل أو المستودع. يثبت اختبار مستقل أن ملف JSON غير الكائني يُحجب مبكراً بواسطة بوابة محتوى الملفات، لا بوابة الاتساق.

## حدود الدليل
هذا **تحقق اتساق داخلي غير متصل بالإنترنت**؛ لا يصادق على أن GitHub أصدر التشغيل فعلاً، ولا يثبت أن ملفات القياس أنتجت قبل فك التعمية، ولا يؤكد استقلال الأجهزة والجلسات أو معايرة ppm. يتعين على المراجع العلمي فحص تشغيل GitHub الفعلي وأثره على البايتات والأرشيفات والأدلة الفيزيائية قبل منح أي اعتماد. جميع ملفات الاختبار اصطناعية وليست قياسات غاز.
