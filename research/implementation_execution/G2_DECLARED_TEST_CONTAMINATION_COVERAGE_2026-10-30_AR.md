# G2 — تغطية سلامة جميع مجموعات الاختبار المعلنة وعدم إخفاء تداخل جزئي

التاريخ: 2026-10-30. النطاق: HazRob Tank / فرع البحث فقط.

## الثغرة التشخيصية

كان مؤشر وجود مجموعتين اختبار منفصلتين `test_has_two_disconnected_test_only_declared_identity_components` قد يعيد `true` رغم وجود مجموعة اختبار ثالثة متصلة بالتدريب أو المعايرة أو التحقق. هذا ليس خطأً في العدّ الوصفي، لكنه قد يؤدي إلى استنتاج غير صحيح بأن **كل** الاختبار معزول. احتُفظ بالمؤشر القديم وأضاف التدقيق مؤشرات أكثر تحفظاً.

## مؤشرات جديدة

- `test_all_declared_identity_components_test_only`: يساوي `false` عند رصد أي اتصال بين اختبار وغير اختبار، و`true` فقط إذا كانت كل المكونات الاختبارية نظيفة مع اكتمال حقول الهوية الأربعة، وإلا `null`.
- `test_has_two_clean_declared_components_without_any_test_contamination`: يساوي `true` عند وجود مكونين اختباريين منفصلين على الأقل، وعدم وجود أي مكون اختبار مختلط، واكتمال حقول الهوية؛ `false` عند تداخل مكتشف أو عندما يكون الحد الأعلى للمكونات النظيفة أقل من اثنين؛ وإلا `null`.
- `declared_identity_test_cross_partition_test_group_count`: عدد معرّفات مجموعات الاختبار التي تظهر داخل مكونات مختلطة؛ عند نقص أعمدة الهوية قد يكون هذا حداً أدنى للتداخل المكتشف، وليس عدداً معتمداً للتجارب الفيزيائية.

تربط المكونات معرفات الجلسة ودفعة التعرض والتعرض والعينة الفيزيائية المعلنة، مباشرة أو انتقالياً. لا يؤدي تشارك `device_id` وحده إلى ربط المجموعات. `false` لا يثبت تسرباً فيزيائياً، و`true` لا يثبت استقلالاً فيزيائياً؛ جميعها بيانات وصفية غير موثّقة مستقلاً.

## إعادة الإنتاج والحدود

أُضيفت 12 حالة اختبار اصطناعية في `test_g2_declared_test_contamination_coverage.py` تشمل التلوث الجزئي والانتقالي، نقص الهوية، إعادة استخدام الجهاز، ترتيب الصفوف، وعدم وجود قسم الاختبار.

```sh
python -m unittest discover -s research/implementation_execution -p 'test_g2_*.py' -v
```

تقوم GitHub Actions بتدقيق 80 تقنية وإعادة التشغيل الحتمية وحارس النشر. لا يُعتبر نجاح الاختبارات البرمجية تأهيلاً G2.

المصفوفة المركزية المثبتة: 80 مدخلاً، 14 مصدر بيانات خارجياً، `source_review_ready=0`. ملف `G2_INDEPENDENT_EVIDENCE.json` يحوي `records=[]`؛ واستيعاب أرشيف MQ الخارجي لا يؤهله تلقائياً. ما تزال معايرات التركيز المرجعية القابلة للتتبع والتعرضات الفيزيائية المستقلة والتقسيمات المحجوبة المسبقة والمراجعة العلمية المستقلة مفقودة. لا تعديل على ChemCore Stable أو Android أو الفريموير أو main؛ ولا اعتماد G2 أو G3.
