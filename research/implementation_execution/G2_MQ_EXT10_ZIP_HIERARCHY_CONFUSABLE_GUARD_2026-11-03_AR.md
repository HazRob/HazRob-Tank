# G2 — ضبط تعارض مسارات الملفات والمجلدات وفواصل Unicode في أرشيف MQ-EXT-10 (3 نوفمبر 2026)

## نقطة البداية والنطاق
فرع البحث `research/chemcore80-central-evidence-gap-analysis-20261021`، والالتزام السابق `43b42345d65d586ea4d5bc1a9a252ea5a61ac9cf`. تأكد اكتمال نجاح 21/21 تشغيل GitHub Actions للالتزام السابق، بما فيها بوابتا G2. التعديل مقتصر على فاحص أرشيف المصدر واختباراته ووثيقة المنهجية ونقطة الاستئناف.

## الثغرة
كان الفاحص يكتشف تكرار المسار الصريح لكنه لا يرفض وجود ملف عادي بالاسم الذي يمثل مجلداً ضمنياً لعضو آخر؛ مثال: `Data/Ethanol` كملف مع `Data/Ethanol/Ea-C1_R01.txt`، سواء ظهر الملف قبل القياس أو بعده. كذلك قد تحول NFKC الفاصل `／` أو النقطتين `．．` داخل اسم مكوّن إلى فاصل مسار أو `..` بعد مرحلة فحص المسارات الأصلية. هذا يترك هوية أعضاء الأرشيف ملتبسة ويتيح إخفاء ملفات عن تصنيف مصدر الإيثانول.

## التعديل
- فحص كل مكوّن مسار بعد NFKC ورفض الفواصل المستحدثة `/` و`\\` والنقطتين `..` والمكوّن `.`؛ الاحتفاظ بالاسم الأصلي دون تعديل.
- إنشاء مجموعتين منفصلتين لمسارات الملفات العادية وللمجلدات الضمنية بعد NFKC وcasefold؛ رفض تعارض ملف/مجلد في ترتيبَي الأعضاء باستخدام `ARCHIVE_FILE_DIRECTORY_CONFLICT`.
- السماح بالمجلدات الصريحة السليمة التي سبق ظهورها ضمنياً، وعدم تحويل هذه الضوابط إلى أي ادعاء بشأن صحة قياسات المصدر.
