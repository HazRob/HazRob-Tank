# G2 — تدقيق سلامة بيانات تقرير إعادة تشغيل أرشيف MQ4 (1 نوفمبر 2026)

## النطاق
هذه بوابة بحثية لسلامة المصدر وليست اعتماداً لقياس الغاز. تراجع الدالة `verify_original_archive` الأرشيف الخام الأصلي المحدد ببصمة SHA256 وتعيد اشتقاق الإحصاءات من CSV، وتراجع الآن أيضاً **بيانات تعريف تقرير إعادة التشغيل** قبل قبول أي تنبؤات مقترنة.

## المشكلة المكتشفة
كان بالإمكان تغيير بعض حقول تقرير إعادة التشغيل التاريخي دون اكتشاف ذلك إذا بقيت بصمات الأرشيف والعضو ومخرجات `derived` متطابقة. تشمل الحقول التي لم تُفحص سابقاً: `schema` و`source_id` و`raw_member_bytes` و`raw_replayed_in_this_execution` و`summary_fields_verified` وأعلام التأهيل العلمي. لا يعني تغيير العلم داخل JSON وجود دليل مستقل، لكنه يفسد سلامة سلسلة الاستدلال.

## المعالجة
أُضيفت `validate_replay_metadata` كشرط سابق لإعادة اشتقاق النتائج؛ تتحقق من هوية المخطط والمصدر، وبصمتي الأرشيف والعضو، وحجم CSV الصحيح مع رفض النوع المنطقي، ومن اكتمال التقرير، وتفرض أن تبقى أعلام `g2_qualified` و`g3_tank_qualified` والاستقلال الفيزيائي والمعايرة المرجعية والاختبار المحجوب `false` بالضبط. ترفض أيضاً غياب `derived` أو تغييره. لا تُغيّر البيانات المرجعية المثبتة.

## إعادة الإنتاج
شغّل من جذر المستودع:

```bash
PYTHONPATH=research/implementation_execution python -m unittest research/implementation_execution/test_g2_mq4_source_row_authentication.py -v
```

تتضمن الاختبارات 12 حالة جديدة بأرشيف ZIP وCSV **اصطناعيين** وبصمات اختبار موقتة. لا يُضمّن الأرشيف الأصلي في CI ولا تنبؤات الصفوف الأصلية. يُنتظر تشغيل مجموعة G2 الكاملة في GitHub Actions للتحقق من عدم حدوث انحدار.

## ضوابط الاعتماد
تبقى `G2_INDEPENDENT_EVIDENCE.json` دون سجلات مؤهلة، و`g2_pass_candidates=0` و`g2_blocked=80` و`source_blocked=14`. إثبات المصدر أو نجاح الاختبارات الاصطناعية لا يثبت استقلال التعرضات أو صلاحية ppm أو الأداء المستقبلي. لا ترقية إلى G2/G3 ولا تعديل ChemCore Stable أو التطبيق أو الفريموير.
