# G2 — تدقيق تداخل معرّفات الجلسات والدفعات والأجهزة بين المجموعات (2026-10-30)

## النطاق
أُضيفت أداة بحثية مستقلة `g2_declared_provenance_overlap_audit.py` لقراءة CSV الخاص بالتنبؤات/التعرضات، وفحص الحقول الاختيارية `session_id` و`exposure_batch_id` و`device_id` مقابل `group_id`. تفحص الأداة استخدام المعرّف المعلن نفسه في أكثر من مجموعة وتعيد قائمة مرتبة ومعيارية؛ كما تحسب بصمة SHA256 دلالية ثابتة أمام إعادة ترتيب الصفوف وتُخرج JSON حتميّاً.

## التمييز العلمي
تكرار الجهاز عبر مجموعتين **لا يعني** تسرب بيانات بالضرورة، لأن الجهاز نفسه قد يُستخدم في تجارب مستقلة. كذلك تكرار الجلسة أو دفعة التعرض عبر مجموعات مختلفة هو **مؤشر يستدعي مراجعة بروتوكول التقسيم**، وليس دليلاً كافياً على تسرب فعلي. غياب أحد حقلي الجلسة أو الدفعة يجعل النتيجة الإجمالية `null` (غير متحقق)، لا `false` (سليم). المعرّفات المعلنة غير موثقة من مصدر خارجي، ولا تثبت هوية العينة أو استقلال التعرضات.

## إعادة الإنتاج
```bash
python -m unittest discover -s research/implementation_execution -p 'test_g2_declared_provenance_overlap_audit.py' -v
python research/implementation_execution/g2_declared_provenance_overlap_audit.py --predictions /path/to/declared_predictions.csv --output /path/to/overlap.json
```
تتضمن الاختبارات الاصطناعية الثمانية: إعادة استخدام الجهاز دون اتهام تلقائي بالتسرب، تداخل الجلسات، تداخل الدفعات، البيانات الوصفية الناقصة، المعرّفات غير المعيارية، الثبات عند إعادة ترتيب الصفوف والتسميات العربية، قراءة CSV، والترويسات المكررة/الصفوف الفارغة.

## الأدلة والقيود
- التحقق المحلي: **8/8 اختبارات اصطناعية ناجحة**؛ لا تمثل قياسات غازات حقيقية.
- قاعدة المراجع المركزية المثبتة ونطاق **80 تقنية / 14 مصدر بيانات خارجي** لم يتغيرا.
- لم تُضف قياسات تعرّض فيزيائية جديدة أو شهادات معايرة أو مجموعات اختبار محجوبة مستقلة. الحالة الموروثة: `g2_pass_candidates=0`, `g2_blocked=80`, `source_qualified=0/14`, `records=[]`.
- الأداة **تشخيصية منفصلة**، ولا تغيّر درجات المرشحين أو بوابة اعتماد G2 ولا تعتمد أي تقنية. يجب فحص GitHub Actions للالتزام الذي أضيفت فيه الاختبارات قبل تسجيل اجتياز CI.
- لم يُعدّل ChemCore Stable أو تطبيق Android أو الفريموير أو الفرع الرئيسي.

## شرط التأهيل المتبقي
لا يمكن تحويل هذه المؤشرات إلى حكم على الاستقلال الفيزيائي قبل تزويدها بمعرّفات تعرض/عينة/جلسة/جهاز موثقة، وشهادات معايرة مرجعية قابلة للتتبع، وتقسيمات holdout عمياء محددة مسبقاً. لا اعتماد G2 أو G3 من هذه الأداة.
