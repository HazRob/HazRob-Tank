# G2 — شرط التنوع التصنيفي لمجموعة الاختبار المحجوبة (2 نوفمبر 2026)

## الفجوة التي عولجت
كانت بوابة إعادة حساب دقة التصنيف قادرة على احتساب قيمة صحيحة رياضياً حتى عندما تتكون جميع التعرضات المحجوبة من فئة مرجعية واحدة. مثل هذا الاختبار لا يثبت قدرة منظومة ChemCore على **التمييز بين الغازات**؛ وقد يحقق مصنف ثابت دقة مرتفعة بلا قدرة تمييزية.

## التعديل
أضيف تحقق مستقل في `g2_cross_artifact_gate.py` لا يعمل إلا عند `metric_name=classification_accuracy`. يُستخرج توزيع الفئات حصرياً من `gas_reference_id` في `group_manifest.csv` للصفوف التابعة لمجموعات `test_group_ids` الموثقة. لا تُحتسب تسميات التدريب أو المعايرة ضمن الاختبار المحجوب.

- `BLIND_TEST_SINGLE_REFERENCE_CLASS`: جميع التعرضات المحجوبة ذات فئة مرجعية واحدة، حتى لو توزعت على مجموعات فيزيائية مختلفة.
- `BLIND_TEST_TARGET_LABELS_UNAVAILABLE`: غياب صفوف الاختبار أو غياب تسمية مرجعية لأي تعرض محجوب.
- لا يمنح وجود فئتين أو أكثر أهلية علمية بحد ذاته؛ يستمر التحقق من استقلال المجموعات، وأصالة البيانات الخام، ومعايرة المرجع، وصحة التنبؤات، وإعادة حساب الدقة وفترات الثقة.

هذا **حد أدنى** لا يثبت تغطية جميع الفئات أو صلاحية القدرة الإحصائية. تتطلب دراسة القوة الإحصائية ومعدلات الخطأ لكل فئة بروتوكولاً مسبقاً وعينات فيزيائية مستقلة. ولا يطبق شرط التنوع هذا تلقائياً على مقاييس الانحدار؛ إذ تبقى تلك المقاييس محجوبة بواسطة `METRIC_FAMILY_NOT_RECOMPUTABLE` حتى توفير محول إعادة حساب مستقل.

## إعادة الإنتاج
```bash
python -m unittest discover -s research/implementation_execution -p 'test_g2_*.py' -v
python research/implementation_execution/g2_evidence_audit.py --output /tmp/g2_audit_results.json
```

تتحقق خمس حالات اصطناعية من: قبول التعدد الأساسي، رفض الفئة الواحدة مع مجموعتين مستقلتين، عدم احتساب فئات التدريب/المعايرة، رفض الحقيقة المرجعية المفقودة، واستقلال قواعد مقاييس الانحدار. يجب أن تنجح بوابة GitHub Actions على الالتزام النهائي قبل اعتماد سلامة التنفيذ البرمجي.

## حدود الدليل ونقطة الاستئناف
آخر حالة موثقة قبل هذا التعديل: `g2_pass_candidates=0`، `g2_blocked=80`، `source_blocked=14`، وسجل الأدلة المستقلة `records=[]`. لم تُضاف قياسات غاز حقيقية أو أرشيف الإيثانول الأصلي. نجاح الاختبارات الاصطناعية لا يمثل اعتماد G2 أو G3. التغييرات مقصورة على فرع البحث؛ لا تعديل على ChemCore Stable أو Android أو الفريموير أو main. بعد فحص CI، الأولوية للقياسات الفيزيائية المحجوبة والمُجمعة بحسب الوحدات المستقلة والمعايرة المرجعية القابلة للتتبع.
