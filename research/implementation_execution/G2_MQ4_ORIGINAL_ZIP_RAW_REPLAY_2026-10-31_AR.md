## قابلية إعادة الإنتاج وحدود CI
الشيفرة: `g2_mq4_original_zip_replay.py`، التقرير المثبت: `G2_MQ4_ORIGINAL_ZIP_RAW_REPLAY_2026-10-31.json`، والاختبارات الاصطناعية: `test_g2_mq4_original_zip_replay.py`. للتكرار، ضع الأرشيف الأصلي في مسار محلي وشغّل:

```bash
python research/implementation_execution/g2_mq4_original_zip_replay.py \
  --archive /path/to/HazRob_MQ_Reference_Real_Measurements_2026-10-30.zip \
  --intake research/implementation_execution/G2_MQ_LIBRARY_RAW_INTAKE_2026-10-30.json \
  --lodo research/implementation_execution/G2_MQ4_LODO_TWO_WAY_PURGE_RAW_REPLAY_2026-10-30.json \
  --segments research/implementation_execution/G2_MQ4_STRICT_CONTIGUOUS_SEGMENTS_2026-10-30.json \
  --multiscale research/implementation_execution/G2_MQ4_MULTISCALE_DAY_CONTEXT_EMBARGO_2026-10-30.json \
  --output /tmp/mq4_raw_replay.json
```

لا يتضمن مستودع GitHub الأرشيف الأصلي؛ لذلك تختبر GitHub Actions الشيفرة ببيانات اصطناعية وتتحقق من وجود التقرير المثبت ومنع الترخيص العلمي، **ولا تعيد تشغيل الأرشيف الخام في CI**. إعادة الحساب المحلي باستخدام نسخة الأرشيف المثبتة ببصمتها خطوة مستقلة عن تدقيق التقارير فقط.
