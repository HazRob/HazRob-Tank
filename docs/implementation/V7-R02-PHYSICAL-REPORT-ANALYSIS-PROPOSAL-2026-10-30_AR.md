## 3. التصور البصري المبدئي للمناقشة
**هوية كل صفحة ثابتة G15–G18:** خلفية بيضاء، Header أسود مع اللوجو السداسي الرسمي يمينًا والعنوان 15pt Bold أصفر `#FFBE00` وسطًا ووقت القياس يسارًا بالأبيض، Footer رمادي فاتح مع «صفحة n من N» أسود 14pt Bold يسارًا وHazRob ثنائي اللون يمينًا، 5 مم هامش مستهدف، line height 1.15، paragraph spacing صفر، حشوات الجدول 2mm جانبيًا/1mm رأسيًا.

### القسم أ. لوحة القياسات المتاحة مع عدادات Gauge
- بطاقات **درجة الحرارة والرطوبة والضغط** في شبكة متكيفة؛ كل بطاقة = اسم عربي/إنجليزي، قيمة أصلية، الوحدة، شارة جودة المقياس/مرجعه حسب المحرك، **Gauge أو Bullet-scale** واضح لا يكرر الجدول بلا إضافة.
- القياسات الأخرى المسجلة فعليًا (ومنها صوت معاير فقط عند توافره من المحرك) تظهر وفق نفس المعيار من دون فرض حد تشغيلي في الـPDF.
- **اختيار نوع Gauge:** عداد قوسي شبيه مقياس السرعة، بقيمة رقمية كبيرة، وتدرجات داكنة واضحة؛ إذا أرجع المحرك `threshold/status` تظهر مناطق المقارنة من مخرجاته. إن لم ترجع العتبة، يعرض عداد القراءة دون علامات خطر.

### القسم ب. جدول القراءات وسلامة الاستقبال
- رؤوس `القياس / Measurement`, `القيمة / Value`, `الوحدة / Unit`, `المصدر / Source`, `الحالة / Engine state`؛ أسود Bold على أصفر برتقالي، حدود سوداء.
- يستخدم التلوين فقط لتبيان حالة المحرك (من دون استنباط قرار ثانٍ). تُختصر العناصر غير المتاحة في جدول ذي مساحة صغيرة، مع إبقاء مرجع الحالة واضحًا.
- الميكروفون: يحفظ RMS وPeak-to-Peak في كتلة «تشخيصية»، ويمنع خلطها مع dBA.

### القسم ج. التحليل الإحصائي — إن أرسله المحرك
- عدد القياسات، المدى الزمني الحقيقي، `mean/median/max/min/SD/P95`، `time above applicable limit` **إذا كانت مخرجات المحرك توفر هذه المؤشرات من سلسلة فعلية**.
- الرسم المقترح: `bullet+threshold band` للمقارنة المسموحة، و`ECDF / distribution / run chart` إن وُجدت عينات مؤرخة؛ لا رسوم إحصائية متخيلة لملف `snapshot` فقط.

### القسم د. خلاصة وتفسير
- `Measurement quality / جودة القياس`؛ `Reference comparison / المقارنة المرجعية`؛ `Data limitations / حدود البيانات`؛ خلاصة ثنائية اللغة من مخرجات المحرك.

## 4. نقطتا قرار مقترحتان للنقاش
**R02-D01 — كثافة العدادات:** خيار أ: ثلاث عدادات كبيرة للحرارة والرطوبة والضغط، وبقية المؤشرات في جدول؛ خيار ب: عداد صغير لكل قياس حقيقي متوفر، مع لوحة كبرى للقياسات الرئيسية. أوصي **ب** لأنه مرن ويلائم التوسع المستقبلي.

**R02-D02 — شكل عرض المؤشرات غير المتاحة:** خيار أ: جدول مضغوط في الصفحة الأولى؛ خيار ب: جدول مستقل في صفحة تقنية عند كثرتها. أوصي بخيار **أ** إلى أن تزيد المعلومات عن سعة 12pt.

**R02-D03 — التحليل الإحصائي:** يدرج فقط إذا كان **المحرك يصدّر المؤشرات/السلسلة**؛ وإلا تُثبت رسالة «البيانات الحالية لقطة فورية، لا توجد سلسلة زمنية» بدل مخطط إحصائي زائف.

**R02-D04 — حدود المقارنة:** عرض المقارنات التي أعلنها **محرك القياسات** فقط؛ لا إنشاء Rule في PDF حتى لو القيمة 90 dBA كانت مكتوبة سابقًا.
