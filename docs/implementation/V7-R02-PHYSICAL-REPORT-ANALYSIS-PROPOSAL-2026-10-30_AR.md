## 3. التصور البصري المبدئي للمناقشة
**هوية كل صفحة ثابتة G15–G18:** خلفية بيضاء، Header أسود مع اللوجو السداسي الرسمي يمينًا والعنوان 15pt Bold أصفر `#FFBE00` وسطًا ووقت القياس يسارًا بالأبيض، Footer رمادي فاتح مع «صفحة n من N» أسود 14pt Bold يسارًا وHazRob ثنائي اللون يمينًا، 5 مم هامش مستهدف، line height 1.15، paragraph spacing صفر، حشوات الجدول 2mm جانبيًا/1mm رأسيًا.

### القسم أ. لوحة القياسات المتاحة مع عدادات Gauge
- بطاقات **درجة الحرارة والرطوبة والضغط** في شبكة متكيفة؛ كل بطاقة = اسم عربي/إنجليزي، قيمة أصلية، الوحدة، شارة جودة المقياس/مرجعه حسب المحرك، **Gauge أو Bullet-scale** واضح لا يكرر الجدول بلا إضافة.
- القياسات الأخرى المسجلة فعليًا (ومنها صوت معاير فقط عند توافره من المحرك) تظهر وفق نفس المعيار من دون فرض حد تشغيلي في الـPDF.
- **اختيار نوع Gauge:** عداد قوسي شبيه مقياس السرعة، بقيمة رقمية كبيرة، وتدرجات داكنة واضحة؛ إذا أرجع المحرك `threshold/status` تظهر مناطق المقارنة من مخرجاته. إن لم ترجع العتبة، يعرض عداد القراءة دون علامات خطر.

### القسم ب. جدول القراءات وسلامة الاستقبال
- رؤوس `القياس / Measurement`, `القيمة / Value`, `الوحدة / Unit`, `المصدر / Source`, `الحالة / Engine state`؛ أسود Bold على أصفر برتقالي، حدود سوداء.
- يستخدم التلوين فقط لتبيان حالة المحرك (من دون استنباط قرار ثانٍ). تُختصر العناصر غير المتاحة في جدول ذي مساحة صغيرة، مع إبقاء مرجع الحالة واضحًا.
- الميكروفون: يحفظ RMS وPeak-to-Peak في كتلة «تشخيصية»، ويمنع خلطها مع dBA.

### القسم ج. التحليل الإحصائي — إن أرسله المحرك
- عدد القياسات، المدى الزمني الحقيقي، `mean/median/max/min/SD/P95`، `time above applicable limit` **إذا كانت مخرجات المحرك توفر هذه المؤشرات من سلسلة فعلية**.

### القسم د. خلاصة وتفسير

1. **25–35 مم من أعلى الورقة:** شريط تعريف اللقطة، الحالة العامة وجودة استقبال البيانات، المصدر/وقت القياس، دون حساب حكم جديد.
2. **35–139 مم:** شبكة بطاقات Gauge `3 × 2` قابلة لإعادة الترتيب، عرض البطاقة التقريبي `64mm`؛ الحرارة والرطوبة والضغط، ثم الصوت (إن توفر) والارتفاع التقديري أو التشخيص الفني/الحالة. **اختلاف نوع المؤشر لا يبرر إعادة استعمال تدريج ثابت واحد للجميع**.
3. **140–213 مم:** جدول «القياسات/الحالة/المصدر» مع إعطاء القراءات الصحيحة مساحة أولوية، وتجميع غير المتاح بعرض كثيف دون حذفه أو إخفاء سبب غيابه.
4. **214–267 مم:** منطقة «ملخص المحرك/المراجع والتفسير» + تشخيص الميكروفون في فواصل متوازنة. إذا لم تتوافر بيانات كافية للإحصاء الزمني يوضح: «قياس آني واحد — لا تتوافر إحصاءات زمنية للتجاوز».
5. **حوالي 283–294 مم:** التذييل ضمن أمان الطباعة.

**قاعدة مهمة:** لا يجب رسم Gauge خطورة على مقياس **الضغط الجوي أو الارتفاع أو الفولت** من دون نطاق مقارنة ورمز صادر من المحرك. يجوز إظهار **عداد مستوى محايد** أو `Bullet meter` عددي وصفي يوضح القيمة ومجال الجهاز المصرح به، دون لون يزعم تجاوز حد. يفضل استخدام Gauge ذي مناطق عتبة فقط عندما يوفر المحرك `threshold_reference_id`, `unit`, `averaging_time` و`comparison_status`.

### 7.5 نماذج مخططات غير نمطية مفيدة فعلًا
| المخطط | القيمة الإضافية مقارنة بالجدول | مدخل البيانات |
| --- | --- | --- |
| `Semi-circular Gauge` | مستوى القراءة الحالي بنظرة واحدة، مظهر شبيه عداد السرعة | القراءة/الوحدة/نطاق المحرك أو الجهاز |
| `Bullet range / reference strip` | موقع القراءة بالنسبة إلى مرجع مقارنة عندما أرسله المحرك | `threshold`, `comparison_state`, `unit`, `reference_id` |
| `KPI status matrix` | مقارنة تغطية المستشعرات المفعّلة وغير المتاحة دون إغراق الصفحة بصفوف | حالات القنوات كما أرجع المصدر |
| `Run chart / time series` | رصد اتجاه القيمة وتذبذبها عبر فترة فعلية | `timestamped observations` حقيقية من المسجل |
| `Box / ECDF / exceedance-duration` | فهم التوزيع، المدى، ومدة التجاوز المؤهلة | مخرجات إحصائية من المحرك + زمن/مرجع صالح |
| `Scatter / 3D climate space` | توضيح التفاعل بين متغيرات بيئية بعيّنات متعددة | **سلسلة متعددة الأبعاد**؛ لا يُستخدم لنقطة واحدة أو لمجرد الزينة |

### 7.7 مراجع التحقق العلمي (للمحرك، لا لشروط PDF)
- [OSHA 29 CFR 1910.95](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.95): الحدود وجداول مدة التعرض للضوضاء؛ `90 dBA at 8h` و`85 dBA TWA action level`.
- [CDC/NIOSH noise REL](https://www.cdc.gov/niosh/bulletin/2016/noise.html): `85 dBA TWA/8h`، 3dB exchange.
- [ISO 9612:2025](https://committee.iso.org/cms/live/live/en/sites/isoorg/contents/data/standard/08/13/81317.html): المنهج الحالي لقياس التعرض المهني للضوضاء؛ `ISO 9612:2009` سُحب واستبدل.
- [ASHRAE Standard 55](https://www.ashrae.org/technical-resources/bookstore/standard-55-thermal-environmental-conditions-for-human-occupancy): ظروف الراحة الحرارية عوامل متعددة.
- [ASHRAE 62.1-2025](https://www.ashrae.org/technical-resources/bookstore/standards-62-1-62-2): حدود الرطوبة المرتبطة بتجهيزات التهوية/المباني وشروط انطباقها، لا حدًا عالميًا لكل لقطة RH.
- [ASHRAE 62.1-2022 Addendum e](https://www.ashrae.org/file%20library/technical%20resources/standards%20and%20guidelines/standards%20addenda/62_1_2022_e_20220930.pdf): حد 65% مرتبط بشروط معينة منها التبريد بالتبخير المباشر؛ لا يُعمم دون سياق المرجع.

### 7.8 قرار النقاش المطلوب
1. **شكل البطاقات:** `5` عدادات رئيسية متكيفّة (الحرارة/الرطوبة/الضغط/الصوت/الارتفاع) أم `3` عدادات رئيسية مع لوحتين تشخيصيتين للصوت والارتفاع؟
2. **حجم القياسات غير المتاحة:** صفوف مستقلة ذات حدود لكل بند، أم مصفوفة حالة مضغوطة مع سبب الغياب في الهامش؟
3. **التقرير الآني مقابل التحليل الزمني:** هل يعتمد R02 لقطة فورية مع Gauge فقط، أم إضافة صفحة «تحليل إحصائي» **عند وجود سلسلة قياسات فيزيائية حقيقية مسجلة من المحرك**؟
4. **صفحة A4:** الوضع الافتراضي صفحة واحدة مع Pagination تلقائي، ولا تُخترع بيانات لملء الفراغ.
5. **GHS:** توضع عبارة «لا ينطبق على هذه المؤشرات الفيزيائية / Not applicable» عند الحاجة، بدل رموز كيميائية لا تخص القياسات.

**القرار التنفيذي الحالي:** `DESIGN_PROPOSAL_ONLY — OWNER_APPROVAL_PENDING; NO R02 JAVA MODIFICATIONS`.
