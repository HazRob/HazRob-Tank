## 1. المنتجات وحدود المسار

1. **Android HazRob Tank V9** — تطوير مستقل فوق مصدر Android V8 الحالي، مع الاحتفاظ بمحرك ChemCore Next وسلوك التطبيق والتقارير والبيانات ما لم يُطلب تغيير موثق.
2. **ESP32-Tank Firmware V9** — تطوير فريموير وحدة ESP32 الرئيسية فقط. النسخة المصدرية الموروثة تحمل `ESP32-Tank 0.1.6-v6-quickr0-dev` و`API=4` حسب `firmware/ESP32-Tank/Config.h` وقت فتح المسار. V9 تسمية إصدار مستهدف **وليست بناءً متاحًا حاليًا**.
3. **ESP32-CAM** — خارج هذا النطاق؛ لا يُغيَّر دون متطلب جديد صريح.
4. **ChemCore Next / Stable** — يُحافظ على الفصل بين الأدلة البحثية والتأهيل الميداني؛ لا يُعلن تحقيق G3 أو دقة ppm دون معايرة وتحقق مادي موثّق.

## 2. الوضع المبدئي والتحقق من المرجع

- آخر APK تجريبي موثق داخل README لفرع V8 هو `versionName=8.0` و`versionCode=8` و`com.hazrob.tank`، بتوقيع Debug؛ **ليس إصدار إنتاج**.
- الفريموير في مصدر فرع V8 لا يزال بتعريف V6 و`API=4`؛ لا يُفترض وجود Firmware V8 أو V9 منشور.

- يبدأ تطوير V9 من نسخة مصدرية ثابتة دون دمج آلي لمسارات البحث التجريبية في الفروع الأخرى.

- يضاف لكل تعديل رقم فريد ومواصفة قبول واختبار؛ يُحدد هل يؤثر Android أو Firmware أو كليهما.
