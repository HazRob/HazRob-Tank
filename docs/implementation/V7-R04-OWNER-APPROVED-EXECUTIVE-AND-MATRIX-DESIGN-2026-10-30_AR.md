# R04 — اعتماد المالك: ملخص المخاطر ومصفوفة القياسات

**القرار:** OWNER_APPROVED_DESIGN_ONLY (2026-10-30 23:09 UTC).

- الملخص التنفيذي يضم نتائج مراجع حدود التعرض، ورسوم GHS المرجعية للمرشحين، ومخططات مصغرة لمقارنة PPM بالحد المرجعي مع نوع الحد والجهة والفترة.
- مصفوفة لكل جلسة أو دورة تشمل الحرارة والرطوبة والضغط والارتفاع والضوضاء والاهتزاز والإشعاع وUV والرياح والإضاءة وPM1 وPM2.5 وPM10؛ مع تقسيم الأعمدة إلى صفحات متعددة وتكرار معرف الجلسة.
- إذا سلّم المحرك حالة تجاوز حد مرجعي: خلفية الخلية حمراء #C62828 والنص أبيض #FFFFFF عريض Bold، مع نص الحالة. تقرير PDF لا يحسب شرط تجاوز جديدًا.
- القيم الغائبة تظهر بالرمز `-`. المخططات وقوالب GHS فارغة دون بيانات حقيقية؛ لا شرائط أو أرقام أو حدود مختلقة.
- هذه مرحلة تصميم وحجز مساحات فقط، دون تعديل كود Android أو ChemCore. تصميم بقية صفحات R04 لم يحصل بعد على توقيع بصري نهائي.
