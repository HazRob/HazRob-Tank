# HazRob Tank V3 — محضر اختبارات القبول الميدانية

**الحالة: لم تبدأ الاختبارات على أجهزة المستخدم.** هذه وثيقة تحقق، وليست تصريحاً لتثبيت فيرموير تجريبي أو تشغيل المجنزرات. تاريخ الإنشاء: 2026-10-20.

مرجع القرارات: [سجل المتطلبات](../requirements/V3-ANDROID-BACKLOG-2026-10-20.md)؛ مرجع التقدم: [سجل التنفيذ](V3-EXECUTION-LOG.md)؛ [قائمة بوابات الإصدار](V3-RELEASE-QUALIFICATION.md).

## المتطلبات المسبقة

- لا تُستخدم ملفات `UNRELEASED` لتشغيل روبوت متحرك قبل إجازة مسؤول السلامة ومراجعة التوصيلات الفعلية. يوثَّق رقم SHA256 للملفات ونسخة APK وفيرموير ESP32-Tank كلٌ على حدة.
- فحص حركة المحركات الأولي **والمجنزرات مرفوعة عن الأرض ومثبتة جيداً** وبوجود وسيلة فصل التغذية فوراً. يبدأ التحكم بسرعة منخفضة وتُراجع نقطة التعادل الفعلية لكل سيرفو.
- يحفظ المختبر نسخة احتياطية من قاعدة بيانات التطبيق قبل أي ترقية أو استيراد. لا تُحذف النسخة السابقة لاختبار توقيع APK مختلف.
- ما لم توجد بيانات فعلية، تكون نتيجة الاختبار **لم يُختبر**، لا «ناجح». تميَّز اختبارات CI عن اختبارات الهاتف والروبوت.

## سجل الاختبار

| المعرف | الاختبار | النتيجة المطلوبة | الحالة الأولية |
| --- | --- | --- | --- |
| H-01 | توصيل السيرفو اليساري GPIO16 والأيمن GPIO17 | اتجاه صحيح، تعادل ثابت دون حركة غير مقصودة؛ إيقاف كلا السيرفوين عند الأمر | لم يُختبر |
| H-02 | انقطاع أوامر القيادة لمدة أكثر من 500ms | يتحول السيرفوان إلى التعادل ولا توجد عودة عكسية ذاتية | لم يُختبر |
| H-03 | فصل Wi-Fi مباشر/فصل MQTT بعيد | توقف مباشر وآمن، ولا تُستأنف الحركة دون أمر مشغل جديد | لم يُختبر |
| H-04 | أمر إيقاف الطوارئ E-STOP وإعادة التسليح | الأمر يوقف ويقفل الحركة حتى إعادة التسليح المصرح بها | لم يُختبر |
| H-05 | منظومة Echo وحساسات MQ الثمانية وADS1115 ×2 وBME والصوت وLDR | قراءة قنوات فعلية وأعلام صحة ووحدات صحيحة؛ Echo ينبه فقط، ولا يظهر IR غير مركب | لم يُختبر |
| A-01 | دخول التطبيق دون اتصال | جميع الواجهات قابلة للاستعراض دون حركة أو اتصال RobotApi، ووضع القيادة غير فعّال | لم يُختبر |
| A-02 | مراجعة RTL والبطاقات والتحديث | بطاقتان في صف القياسات الفيزيائية، الرمادي الطبيعي، أحمر/أبيض فقط عند حد لحظي مناسب وقراءة صالحة؛ أيقونة التحديث داخل محتوى 6 تبويبات فقط ولا زر في القيادة | لم يُختبر |
| A-03 | الجزيئات | تبويب فرعي مستقل، PM1/PM2.5/PM10 غير مختلطة مع الفيزيائية، بيانات PM غير المتوفرة موضحة صراحة | لم يُختبر |
| A-04 | المعايرة المؤتمتة R0 | 5 دقائق تسخين + 3 قياس + 3 مهلة تشغيل + 3 قياس + 3 مهلة تشغيل + 3 قياس = 20 دقيقة؛ نافذة حفظ واحدة، مقارنة kΩ لكل حساس | لم يُختبر |
| A-05 | إلغاء/اعتماد معايرة R0 | الإلغاء لا يغير القيم؛ الحفظ يعتمد القيم الجديدة للتطبيق وChemCore بعد إعادة التشغيل؛ الجلسات القديمة تبقى على نسبها المسجلة | لم يُختبر |
| A-06 | فصل جلسات المستخدم عن المطور | مسودات المستخدم لا تُنشر، تجارب المطور لا تدخل في تقارير المستخدم؛ جلسة معتمدة واحدة تتضمن قياساً مكتملًا فعلياً | لم يُختبر |
| A-07 | قائمة المخططات ونافذة تكبيرها | الأنواع العشرون تُختبر على بيانات حقيقية مناسبة لنوع كل مخطط؛ لا رسم وهمي، ويكبر الرسم المختار بالنقر عليه | لم يُختبر |
| A-08 | تقرير موقع وجلسة PDF/Excel | التقرير النهائي يشمل فقط الجلسات المعتمدة، ولا تزيح 100+ مسودة أحدث تقريراً أقدم معتمداً | لم يُختبر |
| A-09 | PDF القياسات الفيزيائية | التقرير يستعمل البيانات المجمدة عند الضغط، العربية والوحدات والمصادر والتاريخ معروضة دون تقطيع أو خلط PM | لم يُختبر |
| A-10 | ChemCore واستمرار طرق PPM | البصمات والمنحنيات والمعادلات واللوغاريتمات والخوارزميات الموجودة تعمل دون تعطيل لغياب شهادة مرجعية؛ يُعرض الناتج الرقمي التقديري بتمييز المصدر والثقة | لم يُختبر |
| A-11 | أداء الهاتف والانقطاع والاستئناف | لا تعليق للواجهة أو فقد غير مقصود للبيانات، والمعايرة/الجلسات لا تعتمد قياسات ناقصة دون علم المستخدم | لم يُختبر |
| R-01 | توقيع APK وتحديثه | شهادة ثابتة، تثبيت وتحديث دون حذف بيانات المستخدم أو تضارب التوقيع، ثم اجتياز فحص الأمان | محجوب لحين التوقيع |

```text
الروبوت: السيرفوهات والمجنزرات مرتفعة؟ وسيلة قطع التغذية متاحة؟
البيانات/الجلسة المستخدمة:
المتوقع:
النتيجة الفعلية:
PASS / FAIL / NOT TESTED:
المرفقات أو رابط GitHub issue:
ملاحظات إعادة الإنتاج:
```

**لا يُغيَّر أي صف إلى PASS إلا بدليل من الاختبار الفعلي.** لا يكفي بناء GitHub Actions أو اختبار JVM لإثبات سلوك السيرفوهات أو المخططات على الهاتف. بعد انتهاء كل دفعة اختبار تُوثق النتيجة في [سجل التنفيذ](V3-EXECUTION-LOG.md) وتُحدَّث بوابات الإصدار.
