# HazRob Tank V8 — P11.5: عرض المرجع المزدوج وأسباب الامتناع داخل الواجهة

**التاريخ:** 2026-11-03  
**فرع التنفيذ:** `feature/tank-v8-implementation`  
**الصفة العلمية:** G1 Android Java/source + محاكي اصطناعي، دون تجربة تعرض غاز مرجعية، ودون رفع حالة G3.

## الاعتماد المرجعي
- `R_air` هو متوسط `Rs` في الهواء النظيف المحفوظ أصلًا للجهاز؛ `R0_source_research = R_air/K_source` هو مرجع مشتق لكل معادلة MQSensorsLib فقط. لا تعديل للمعايرة الدائمة أو حدود الإنذار.
- معاملات المصدر غير مؤكدة مع هيتر الدبابة، لذلك حتى نتائج `ppm` المنتهية **بحثية مشروطة**، وليست هوية غاز أو تقييم تعرض.
- تقرير PDF V7 وExcel P11.4 ثابتان كما أُقرا؛ المرحلة تتعلق بعرض المشغل وحالة الامتناع فقط.

## التنفيذ الفعلي
1. `android/app/src/main/java/com/servoc/app/chemcore/nextintegration/NextResearchOperatorText.java`: مكوّن عرض عربي مستقل، يقرأ فقط `scientific_source_diagnostics/2` المرتبط بقرار Next، ويُلخص مجموع النماذج والحسابات غير المتاحة والنماذج ذات R0 مشتق. يطبع لكل نموذج `Rs` و`R_air` و`K` و`R0_source` والنسبتين عندما توجد. لا يعيد حل معادلات الغاز، ولا يخترع `ppm` مفقودًا، ولا يصدر إنذارًا، ويذكر بوضوح عدم اعتماد المرجع/السخان.
2. `NextScientificDiagnostics.java`: إضافة `failure_reason_code` **لكل مصدر غير قابل للحساب** في الـ49 السابقة والـ13 MQSensorsLib، مع التمييز بين: لقطة Next غائبة، الريلاي OFF في اللقطة، غياب الحساس، جودة غير VALID، تعريف R0 لا يشهد `AIR_RS_MEAN`، غياب `R_air`، غياب `Rs` الموجب، معاملات أصل معطوبة، تحويل المرجع أو نتيجة عددية غير صالحة. حقول إضافية، دون تغيير صيغة القرار أو حسابات المعادلات.
3. `MeasurementsTab.java`: بطاقة `dualReferenceCard` ظاهرة في نتائج Next فقط، ويمكن نسخ نصها؛ تُخفى عند الرجوع للجلسات القديمة أو عند عدم وجود تحليل. قسم التفاصيل يذكر أسباب عدم الحساب وكل معادلة على حدة، بدل الرمز `NOT_EVALUABLE` وحده. تنسيق مقارنات المواد المرجعية محايد ولا ينقل لون تنبيه مهني سابق إلى حسابات بحثية غير مؤهلة.
4. **التمييز بين ADC والفولت:** بطاقة MQ الحية لا تعرض `q.adc` أو `q.ao` تلقائيًا بوحدة V؛ تحفظهما كقيمتين أصليتين غير مثبتة الوحدة، وتعرض `VADC` فقط من `adc_voltage_v` أو `voltage_v` إذا كان رقمًا منتهيًا. ويعرض مصدر R0 المخزن بتعريفه الأصلي من `ManualR0Calibration.getDefinition`، فلا يسمي القيمة المخزنة مرجع مصنع بحثي.
5. **جلسات القياس:** بعد مراجعة `FieldSessionsTab.java` ظهر أن فشل القياس يُظهر `failReason` وأثر عدم الاعتماد وإعادة المحاولة بشكل صريح. لا تغيير لهذا المسار؛ `NOT_EVALUABLE` البحثي ليس فشل قياس ميداني بحد ذاته.
