# V8 Emissions — نقطة استئناف: سجل محرك واحد = قياس واحد

**قرار المستخدم، 2026-11-03:** كل أمر «استحداث» يُعرّف محركًا مستقلًا، ولكل محرك **نتيجة قياس واحدة فقط**، وليس مجموعة جلسات دورية.

## التنفيذ
- `EmissionSessionStore.java`: حفظ تعريف محرك مستقل في SQLite، نتيجة واحدة اختيارية لكل معرّف مع قيد `UNIQUE(engine_id)`، و`ON DELETE CASCADE`. عند ترقية السجلات القديمة، تُحتفظ أحدث نتيجة فقط لكل محرك.
- `EmissionEngineConfig.java`: وصف فني مستقل يشمل الوقود والاشتعال أو قطر الأسطوانة والقوة الحرارية والساعات ونسبة الاستغلال والكبريت وO₂ وحالة الغاز الجاف، مع `null` للقيم المجهولة.
- `EmissionEngineEditor.java`: نافذة استحداث تتضمن هذه الخانات والقوائم وشرح متطلبات انطباق جدول IFC 1.1.2 قبل التأكيد.
- `EmissionsTab.java`: يشتق فئة IFC من تعريف المحرك، وينفّذ القياس الأول ويحفظ **نتيجة واحدة** لكل محرك. بعد القياس يظهر خيار «إعادة القياس» مع **تأكيد صريح** لاستبدال النتيجة القديمة، وليس إنشاء جلسة ثانية؛ يُحظر الاستبدال الصامت. إذا فشل التسجيل تبقى النتيجة السابقة محفوظة ولا يُحذف شيء. تغيير المحرك يغيّر المصفوفة والتقرير.
- `EmissionSessionInstrumentedTest.java`: اختبار مستقل لمحركين، مع رفض الإضافة الثانية، وإجازة الاستبدال الصريح ضمن السجل الواحد دون تعديل المحرك الآخر.

**حدود عملية الحذف:** حذف السجل يزيل المحرك وقياسه من التطبيق. أي PDF تم تصديره إلى مجلد Downloads هو نسخة مستقلة لا تزال على جهاز المستخدم، ولن تحذفه قاعدة البيانات تلقائيًا.

**الحالة:** يجب مراجعة نتائج GitHub Actions للتحقق من تجميع Android واختبار Android12؛ ولا يُصدر APK قبل بوابة إصدار V8. لا تُعتبر تقديرات منحنيات MQ شهادة امتثال IFC ما لم تكن بيانات العادم وأساس القياس قابلين للمقارنة.

**المستودع:** `HazRob/HazRob-Tank`، الفرع `feature/tank-v8-implementation`.
